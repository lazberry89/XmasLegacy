# 코드 점검 정리 (2026-11-29)

common / paper / velocity 소스를 전부 읽고, 오류가 나거나 데이터가 사라질 수 있는 곳과 비효율적인 곳을 고쳤다.
밸런스와 기획은 바꾸지 않았다. 결정이 필요한 것은 맨 아래 "남겨둔 것"에 있다.

검증: 컴파일, `:paper:test` `:velocity:test`, 두 shadowJar 빌드 통과. **게임 안, 실제 MySQL/Redis에서는 확인하지 않았고 배포도 하지 않았다.**

## 1. 데이터가 사라지거나 복사되던 것

- **유저 데이터**: DB 오류를 "신규 유저"로 처리해 기존 행을 덮어쓰던 문제(`SqlUserRepository.loadUser`). 오래된 비상 덤프가 유저를 롤백시키던 문제(저장 성공 시 덤프 삭제).
- **서버 이동**: 이전 서버가 저장을 끝내기 전에 새 서버가 불러오던 문제. 최대 3초 기다린 뒤 불러온다(`UserSaveManager.awaitPreviousServer`). 가방도 같다.
- **가방**: 불러오기에 실패한 가방을 빈 가방으로 저장하던 문제. DB 컬럼을 MEDIUMTEXT로 키웠다(시작할 때 ALTER 실행).
- **입금/이체**: 실패해도 성공으로 처리되던 입금(재화 아이템만 소모됨), 큰 금액의 세금 int 오버플로.
- **시체상자**: 재시작하면 전부 사라지던 문제(비동기에서 월드를 건드림). 같은 자리에서 죽으면 이전 상자를 덮어쓰던 문제, 공허 사망, 상자를 부수거나 폭발시키면 내용물을 못 찾던 문제.
- **주식**: 한 번에 많이 사면 int 한계(21억)에서 값이 멈춰 거의 공짜로 사지던 문제. 1회 구매 상한 2304주(64×36칸)를 넣었다. 종료 시 저장, 삭제한 주식이 되살아나던 문제, 대소문자 불일치.
- **가챠**: 번들이 소모되지 않던 문제, 양손으로 두 번 실행되던 문제, 저장하면 번들 종류가 모두 NORMAL로 바뀌던 문제(예전 파일도 읽힘). `setItemModel("")` 때문에 초기화가 실패하던 문제.
- **상점 GUI**: 시프트 클릭/드래그로 아이템을 넣으면 사라지던 GUI 19종. `ReadOnlyGui`만 구현하면 `ReadOnlyGuiListener`가 막는다.
- **강화**: 강화 모루 연출 중 나가거나 서버가 꺼지면 아이템이 사라지던 문제, 파괴 방지 연출이 실제 손 아이템을 바꿔치기하던 문제.
- **투명 모드**: 해제해도 해제되지 않아 다음 사용 때 갑옷이 지워지던 문제. 종료 시에도 갑옷을 돌려준다.
- **직업 패시브**: 보호구역에서 취소된 파괴/설치/공격에도 경험치·추가 드롭·돈을 주던 문제(농부, 광부, 낚시꾼, 사냥꾼).
- **직업 상점**: 커스텀/Oraxen 아이템이 같은 재질의 일반 아이템으로 팔리던 문제.
- **카지노**: 99개 넘는 코인 지급이 가방/우편에 저장되지 않던 문제, 베팅창이 플러그인에 의해 닫히면 코인이 사라지던 문제.
- **구역**: 월드가 달라도 같은 청크 좌표면 같은 구역으로 보던 문제. 월드가 안 불러와졌을 때 다른 월드로 옮겨 저장되던 문제. 생성이 취소돼도 티켓이 소모되던 문제. 설정 변경 즉시 저장.
- **콜렉터즈 백업**: HuskSync가 인벤토리를 덮어쓰던 순서 문제.
- **온도 구역**: 저장 형식 때문에 파일을 다시 못 읽던 문제.
- **상품/진열대**: 종료할 때만 저장하던 것을 변경할 때마다 저장. 관리자가 손에 든 아이템을 그대로 참조하던 문제(가챠도 동일).

## 2. 오류가 나거나 동작하지 않던 것

- `plugin.yml` softdepend: `oraxen` → `Oraxen`(대소문자 구분), `Multiverse-Core` 추가(월드보다 먼저 켜지면 저장된 위치를 못 읽음).
- Redis 구독이 끊기면 다시 연결되지 않던 문제.
- 기능 클래스 하나가 로드에 실패하면 스캔 전체가 멈추던 문제(`PackageScanner`, `Reflections`).
- `SqlUserRepository.getRank`: 예약어 `rank` 때문에 SQL 오류.
- 항구 이동 명령어가 이동시키지 않던 문제, 리스폰 위치 적용, 나중에 불러온 월드의 스폰 위치.
- 다이아몬드 9개로 다이아 블록을 못 만들던 문제(강화 재료 조합법과 겹침).
- AeroMancer가 무기 없는 사람의 비행까지 취소하던 문제, FlameWeaver 공격자/피해자 뒤바뀜(이제 **불붙은 적에게 1.3배가 실제로 적용됨**), 화염구가 블록을 부수던 문제.
- 도면: 회전해서 만들면 제작자 누락, 다른 스레드에서 아이템 지급, 띄어쓰기 이름을 다른 명령어가 못 찾던 문제.
- 기절: 크래시 후 기절 상태로 남던 문제, 기절한 사람이 남을 살리던 문제.
- 커스텀 몹 목록이 비어 있던 문제(HUNTING), 마법책 중복 생성/삭제 안 됨, 인자 없는 `/role` 오류, `/파티 도움`, 파티 초대 버튼 재사용, NPC 지급품이 인벤토리가 가득 차면 사라지던 문제, 음식 수치 한도, 서버 링크 리로드가 수정 내용을 덮어쓰던 문제 등.

## 3. 느리던 것

- 구역: 이동할 때마다 청크를 불러오던 것, 5초마다 모든 구역 청크를 디스크에서 읽던 것 → 좌표만 사용, 불러온 청크만 처리.
- 온도 구역/텔레포터 파티클: 불러오지 않은 청크는 건너뜀.
- 기절 판정: 모든 피해마다 Redis 조회 → 치명타일 때만. 파티 스코어보드: 파티원마다 Redis 조회 제거.
- 닉네임으로 찾기: 메인 스레드에서 Mojang 서버를 조회하던 것 제거(귓속말, TPA).
- 주식 월드가 없을 때 매초 오류 로그 → 1회.
- 표시용 엔티티가 저장되어 크래시 후 겹쳐 쌓이던 것 → `setPersistent(false)`.

## 수정할 때 주의

- 새 "클릭만 하는" GUI는 `InventoryHolder` 대신 `ReadOnlyGui`를 구현한다. 아이템을 올려두는 GUI(가방, 시체상자, 베팅, 강화, 샘플 편집)는 쓰면 안 된다.
- 보상을 주는 리스너는 `ignoreCancelled = true`. 보호 플러그인보다 뒤에 실행되도록 `MONITOR`.
- `Location.getChunk()`/`getBlock()`은 청크를 불러온다. 자주 도는 코드에서는 `Chunk.getChunkKey(loc)`, `isChunkLoaded()`.
- 접속 직후 인벤토리를 바꾸는 코드는 `PlayerJoinEvent` 말고 `PlayerDataReadyEvent`.

## 남겨둔 것 (결정 필요)

- **주가 하락**: `StockUpdater` 식이 평균 -20%이고 장이 열려 있는 동안 매초 돈다. 가격이 최저가로 내려간다. 의도가 `((raw³+1)/2)·0.45−0.20`이었는지, 개장 때 1번만 도는 것이었는지 확인 필요.
- 대장장이 도구가 30초마다 프리즘 5개를 무료로 준다.
- 광부: 직접 설치한 광석을 다시 캐도 경험치를 준다.
- 시체상자는 아무나 열 수 있다(소유자 확인 여부).
- `/직업선택` GUI를 여는 코드가 없음, 주식 보관함 미사용, 사냥터 저장 안 됨, 콜렉터즈 게임 미완성.
- 서버가 꺼질 때 열려 있던 코인플립/강화 창의 아이템, 돌고 있던 슬롯머신 판돈은 사라진다.
- 포탈, 진행 중인 건축은 정상 종료 때만 저장된다. 비상 덤프는 서버별 파일이다.
