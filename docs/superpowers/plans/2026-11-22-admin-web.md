# 관리자 웹 대시보드 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Velocity 플러그인이 키 로그인 방식의 읽기 전용 관리자 웹(유저·문의·가방·우편함·후원·업적 탭)을 띄운다.

**Architecture:** `velocity` 모듈의 `admin` 패키지에 JDK `HttpServer` 기반 서버를 두고, 정적 화면(`resources/admin-web/`)과 JSON API를 함께 서빙한다. 키는 `plugins/xmaslegacy-velocity/admin-keys.yml`, DB 접속은 기존 `web.database.*` 설정을 쓴다. 프레임워크의 `@Components` + `Initiator`(`init()`/`close()`)로 생명주기를 붙인다.

**Tech Stack:** Java 21, `com.sun.net.httpserver`, SnakeYAML(Velocity 런타임 포함), Gson(velocity-api 포함), mysql-connector-j(이미 shade), JUnit 5(테스트 전용 추가), 바닐라 HTML/CSS/JS.

**Spec:** `docs/superpowers/specs/2026-11-22-admin-web-design.md`

## Global Constraints

- 모든 DB 접근은 `SELECT`만. INSERT/UPDATE/DELETE 금지.
- 키 파일 경로: `<dataDirectory>/admin-keys.yml`, 형식 `keys: [ "..." ]`. 없거나 비면 웹 서버를 띄우지 않고 `log.warn`.
- `.gitignore`에 `admin-keys.yml` 추가.
- 세션: 랜덤 32바이트 토큰(Base64URL), 쿠키 이름 `XL_ADMIN`, `HttpOnly; SameSite=Strict; Path=/; Max-Age=43200`, 서버 메모리 보관 12시간.
- 로그인 실패 제한: IP당 60초 창에 5회. 초과 시 429.
- 키 비교: `MessageDigest.isEqual`(상수 시간).
- 설정: `config.yml`에 `admin-web: { enabled: true, port: 8095, bind: "0.0.0.0" }`.
- 외부 CDN 금지(폰트 포함). 픽셀 폰트는 Galmuri11 woff2 1개를 jar에 포함(OFL).
- 새 런타임 의존성 추가 금지.

## Review Focus

- 키 파일을 서버 가동 중 수정/삭제: 수정은 다음 요청부터 반영, 삭제되면 모든 로그인 거부(기존 세션은 만료까지 유지). → Task 1 테스트.
- 가방 YAML에 `null` 슬롯·알 수 없는 컴포넌트·깨진 Base64: 빈 칸/무시/전체 "해석 불가" 항목 하나, 예외로 500 나지 않음. → Task 3 테스트.
- 경로 조작(`/../config.yml`, `/admin-keys.yml`)으로 정적 파일 밖을 읽기: 404. → Task 4 테스트.
- 쿠키 없이/만료된 쿠키로 `/api/*` 호출: 401, 데이터 0바이트. → Task 4 테스트.
- 문의·이름에 들어간 `<script>` 같은 문자열: 화면에 글자로 보이고 실행되지 않음(`textContent`만 사용, `innerHTML`에 데이터 금지). → Task 5 체크.

**Interfaces:**
- Produces: `record ItemView(int slot, String id, int count, String name, String nameColor, List<String> lore, List<String> enchants, String model)`; `static List<ItemView> ItemYamlParser.parse(String base64)` — 빈 슬롯 제외. 해석 불가면 `ItemView(-1, "unknown", 0, "해석 불가", "red", List.of(원문 앞 120자), List.of(), null)` 하나만 반환.

입력 형식(실DB 샘플): Base64 → YAML `items:` 리스트, 원소는 `null` 또는 `{id, count, components: {...}}`. 컴포넌트 값은 SNBT 문자열:
`minecraft:custom_name: '{bold:1b,color:"yellow",text:"태양초 빵"}'`, `minecraft:lore: '[{color:"gray",text:"..."}]'`, `minecraft:item_model: '"oraxen:sunflower_bread"'`, `minecraft:enchantments: '{"minecraft:sharpness":3}'`.

- [ ] **Step 1: 실패 테스트**
  - `parsesCustomNameLoreAndSlot`: 위 샘플(빵 1개를 slot 0, 이후 null 2개)을 YAML로 만들어 Base64 → 결과 1개, `slot 0`, `id "minecraft:bread"`, `count 1`, `name "태양초 빵"`, `nameColor "yellow"`, `lore ["농부만이 만들 수 있는 이 세상을 살아갈 식량입니다."]`, `model "oraxen:sunflower_bread"`.
  - `fallsBackToItemNameThenId`: `custom_name` 없고 `item_name: '{color:"gold",text:"sunflower_bread"}'` → name `"sunflower_bread"`; 둘 다 없으면 name `"bread"`(id에서 네임스페이스 제거).
  - `readsEnchantments`: `'{"minecraft:sharpness":3}'` → enchants `["sharpness 3"]`.
  - `skipsNullSlotsAndKeepsIndex`: `[null, item]` → slot 1.
  - `brokenBase64GivesSingleUnparsedItem`: `"!!notbase64"` → 1개, name `"해석 불가"`, 예외 없음.
- [ ] **Step 2: 실패 확인**
- [ ] **Step 3: 구현** — SNBT는 정규식으로만 추출: text는 `text:"((?:[^"\\]|\\.)*)"`, color는 `color:"([^"]*)"`(첫 매치), 인챈트는 `"([a-z0-9_:]+)":(\d+)`. 전체를 `try/catch (Exception)`로 감싸 해석 불가 항목 반환.

**Interfaces:**

- Produces:
  - `class AdminQueries(String url, String user, String password)` — 공개 메서드는 모두 `Object` 반환(Gson 직렬화 대상, `List<Map<String,Object>>` 또는 `Map`): `overview()`, `users()`, `user(String uuid)`, `inquiries(String status /*nullable*/)`, `bagOwners()`, `bag(String uuid)`, `mailbox()`, `products()`, `advancements()`. 생성자는 연결하지 않음; 메서드마다 `DriverManager.getConnection`. UUID 파라미터는 `PreparedStatement`로만.
  - `class AdminWebServer implements Initiator`, `@Components`. 프레임워크용 `@Inject` 생성자는 `@ConfigValue(path = "web.database.url"/"web.database.user"/"web.database.password") String`, `@ConfigValue(path = "admin-web.port") int`, `@ConfigValue(path = "admin-web.bind") String`, `@ConfigValue(path = "admin-web.enabled") Boolean`를 받고, 키 파일은 `Velocity.directory().resolve("admin-keys.yml")`. 테스트용 생성자 `AdminWebServer(AdminQueries q, AdminKeyStore keys, AdminSessions s, String bind, int port)`. `int port()` (0으로 띄우면 실제 포트 반환).

**API (모두 JSON, `/api/login` 외 쿠키 필수 → 없으면 401 `{"error":"unauthorized"}`):**

| 메서드 | 경로 | 응답 |
| --- | --- | --- |
| POST | `/api/login` body `{"key":"..."}` | 200 + `Set-Cookie`; 틀리면 401; 제한 초과 429 |
| POST | `/api/logout` | 204, 세션 폐기 |
| GET | `/api/overview` | `{users, totalDollars, pendingInquiries, recentInquiries[5]}` |
| GET | `/api/users` / `/api/users/{uuid}` | 목록 / 상세(+`availablePrefix` 배열로 분리) |
| GET | `/api/inquiries?status=` | 최신순, `player_name` 포함 |
| GET | `/api/bags` / `/api/bags/{uuid}` | `[{uuid,name,itemCount}]` / `{uuid,name,items:[ItemView]}` |
| GET | `/api/mailbox` | `[{id,uuid,name,items:[ItemView]}]` |
| GET | `/api/products` | `[{id,receiver,name,product,granted}]` |
| GET | `/api/advancements` | `Players`·`Advancements`를 `TeamID`로 조인, `[{name,uuid,done:[{namespace,key,progression}]}]` |

UUID→이름은 `users`와 LEFT JOIN, 없으면 UUID 앞 8자.

정적 파일: `/` → `admin-web/index.html`, 그 외 경로는 `admin-web/` 아래 클래스패스 리소스만. `..` 포함 또는 리소스 없음 → 404. 응답 헤더: `Cache-Control: no-store`, `X-Content-Type-Options: nosniff`, `Content-Security-Policy: default-src 'self'; img-src 'self' data:`. 클라이언트 IP는 `exchange.getRemoteAddress()`.

`init()`: `enabled`가 false거나 `keys.hasKeys()`가 false면 `log.warn` 후 리턴. 아니면 `HttpServer.create`, 가상 스레드 executor, 시작 로그 `"Admin web listening on {bind}:{port}"`. `close()`: `server.stop(0)`.

  - `apiWithoutCookieIs401`: `GET /api/users` → 401.
  - `wrongKeyIs401`, `sixthBadLoginIs429`.
  - `loginThenUsersReturnsData`: 올바른 키 로그인 → 쿠키로 `GET /api/users` → 200, 본문에 `"Steve"`.
  - `logoutRevokes`: 로그아웃 후 같은 쿠키로 401.
  - `pathTraversalIs404`: `GET /../config.yml`, `GET /admin-keys.yml` → 404.
  - `rootServesIndex`: `GET /` → 200, `text/html`.
- [ ] **Step 2: 실패 확인** — `./gradlew :velocity:test --tests '*AdminWebServerTest'`
- [ ] **Step 3: 구현** — `AdminQueries`, `AdminWebServer`, `config.yml` 블록. 테스트를 위해 `admin-web/index.html`은 임시 한 줄로 두고 Task 5에서 교체.
